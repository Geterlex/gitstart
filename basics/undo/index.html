Что важно помнить

Git отслеживает не «папку целиком», а состояния файлов и связи между коммитами. Перед каждым действием полезно проверять состояние репозитория.

Отменить незакоммиченные изменения файла
git restore file.txt
Создать новый коммит, отменяющий старый
git revert <hash>
Убрать последний коммит, сохранив изменения в индексе
git reset --soft HEAD~1
Совет: перед потенциально опасной командой выполните git status и убедитесь, что понимаете текущее состояние репозитория.
