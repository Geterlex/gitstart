git log

Показывает историю коммитов.

Показывает историю коммитов.

Назначение

Показывает историю коммитов.

Перед выполнением

Проверьте текущую ветку и состояние репозитория. Это особенно важно для команд, изменяющих историю или рабочие файлы.

Пример использования
git log --oneline
Совет: перед потенциально опасной командой выполните git status и убедитесь, что понимаете текущее состояние репозитория.
