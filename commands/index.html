Команды Git

Основные команды, которых достаточно для большинства учебных и небольших рабочих проектов.

КомандаНазначениеПример
git initСоздаёт новый Git-репозиторий в текущей папке.git init
git cloneКлонирует существующий репозиторий вместе с историей.git clone <url>
git statusПоказывает состояние рабочей области и индекса.git status
git addДобавляет изменения в индекс перед коммитом.git add <file>
git commitСоздаёт коммит из изменений, находящихся в индексе.git commit -m "Сообщение"
git logПоказывает историю коммитов.git log --oneline
git branchПоказывает, создаёт и удаляет ветки.git branch
git switchПереключает текущую ветку или создаёт новую.git switch <branch>
git mergeСливает указанную ветку с текущей.git merge <branch>
git remoteУправляет ссылками на удалённые репозитории.git remote -v
git pushОтправляет локальные коммиты в удалённый репозиторий.git push
git pullПолучает удалённые изменения и интегрирует их в текущую ветку.git pull
git fetchПолучает новые данные с remote без автоматического слияния.git fetch
git resetПеремещает указатель ветки и может изменять индекс и рабочую область.git reset --soft HEAD~1
git revertСоздаёт новый коммит, отменяющий эффект выбранного коммита.git revert <hash>
