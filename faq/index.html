Частые вопросы

Короткие ответы на вопросы, которые обычно появляются в первые дни работы с Git.

Git и GitHub — это одно и то же?

Нет. Git — система контроля версий, а GitHub — сервис для хранения Git-репозиториев и совместной работы.

Нужен ли интернет для Git?

Для локальных коммитов, веток и истории — нет. Интернет нужен для операций с удалённым репозиторием.

Что писать в сообщении коммита?

Коротко описывайте результат изменения: «Добавить форму входа», «Исправить расчёт суммы», «Обновить README».

Можно ли отменить коммит?

Да. Способ зависит от того, опубликован ли он. Для опубликованного коммита безопаснее revert, для локального часто подходит reset.

Что такое origin?

Обычное имя основного удалённого репозитория. Его можно изменить или использовать другое имя.
