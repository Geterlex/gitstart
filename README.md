# GitStart

Статический учебный сайт по Git для начинающих.

## Быстрый запуск локально
Откройте `index.html` двойным кликом или запустите локальный сервер:

```bash
python -m http.server 8000
```

## Публикация через GitHub Pages
1. Создайте публичный репозиторий, например `gitstart`.
2. Загрузите содержимое этой папки в корень репозитория.
3. В GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. После публикации замените `USERNAME` в `sitemap.xml`, `robots.txt` и canonical-ссылках HTML на имя GitHub-аккаунта.

Сайт не требует backend, базы данных или сборщика.


## Локальный запуск
Не открывайте разделы через `file://`: браузер может показывать содержимое папки вместо `index.html`.

Windows: запустите `run_local.bat`, либо в терминале из корня проекта выполните:

```bash
py -m http.server 8000
```

После этого откройте `http://localhost:8000/`.
