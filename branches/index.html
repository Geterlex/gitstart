Ветки Git

Изолируйте работу над функциями, переключайтесь между задачами и объединяйте изменения без хаоса.

Основы ветвления

Ветка — независимая линия разработки. Она позволяет экспериментировать и разрабатывать функции отдельно от основной версии проекта.

Создание ветки

Создайте новую ветку от текущего коммита и начните работу в ней.

Переключение между ветками

Переключайтесь между уже существующими ветками безопасно.

Слияние веток

Объедините готовые изменения из одной ветки с другой.

Удаление веток

После слияния ненужную локальную или удалённую ветку можно удалить.

Конфликты слияния

Конфликт возникает, когда Git не может автоматически выбрать между несовместимыми изменениями.
