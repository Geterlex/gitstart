Полезно знать

Имя origin — обычное соглашение, а не обязательное правило. В одном проекте может быть несколько удалённых репозиториев.

Добавить origin
git remote add origin https://github.com/user/repo.git
Совет: перед потенциально опасной командой выполните git status и убедитесь, что понимаете текущее состояние репозитория.
