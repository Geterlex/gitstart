Удалённые репозитории

Свяжите локальную историю с сервером и научитесь безопасно обмениваться изменениями.

Что такое remote

Remote — ссылка на удалённый Git-репозиторий. Обычно главный удалённый репозиторий называется origin.

Добавление remote

Свяжите локальный репозиторий с удалённым.

Отправка изменений — push

Отправьте локальные коммиты в удалённый репозиторий.

Получение изменений — pull

Получите изменения и сразу интегрируйте их в текущую ветку.

Получение данных — fetch

Загрузите информацию об удалённых ветках без автоматического слияния.
