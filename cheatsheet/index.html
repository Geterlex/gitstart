Шпаргалка Git

Минимальный набор команд, который удобно держать под рукой во время работы.

Старт

git initновый репозиторий
git clone <url>клонировать проект
git statusпроверить состояние

Коммиты

git add .добавить изменения
git commit -m "msg"создать коммит
git log --onelineистория

Ветки

git switch -c <name>создать ветку
git switch <name>переключиться
git merge <name>слить ветку

Remote

git remote -vпоказать remote
git pushотправить коммиты
git pullполучить и объединить
git fetchтолько получить данные
Важно: шпаргалка помогает вспомнить синтаксис, но перед командами reset, rebase и принудительным push лучше понимать последствия.
