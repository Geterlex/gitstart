Как действовать

Не спешите удалять папку .git или использовать --force. Сначала зафиксируйте текущее состояние и прочитайте сообщение Git: оно обычно прямо указывает на причину.

Восстановить файл из текущего коммита
git restore path/to/file
Совет: перед потенциально опасной командой выполните git status и убедитесь, что понимаете текущее состояние репозитория.
