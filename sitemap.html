Команды Git

Справочник основных команд Git.

git init

Создаёт новый Git-репозиторий в текущей папке.

git clone

Клонирует существующий репозиторий вместе с историей.

git status

Показывает состояние рабочей области и индекса.

git add

Добавляет изменения в индекс перед коммитом.

git commit

Создаёт коммит из изменений, находящихся в индексе.

git log

Показывает историю коммитов.

git branch

Показывает, создаёт и удаляет ветки.

git switch

Переключает текущую ветку или создаёт новую.

git merge

Сливает указанную ветку с текущей.

git remote

Управляет ссылками на удалённые репозитории.

git push

Отправляет локальные коммиты в удалённый репозиторий.

git pull

Получает удалённые изменения и интегрирует их в текущую ветку.

git fetch

Получает новые данные с remote без автоматического слияния.

git reset

Перемещает указатель ветки и может изменять индекс и рабочую область.

git revert

Создаёт новый коммит, отменяющий эффект выбранного коммита.
